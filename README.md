# Unicast

An Android app where one broadcaster (the owner) records and uploads audio and goes live, and listeners tune in, play recordings, and download them. No listener accounts needed.

- Live audio: LiveKit Cloud
- Login, database, file storage: Supabase
- Recordings: Opus, 6 kbps, mono
- Live notifications: Firebase Cloud Messaging
- App builds: GitHub Actions

See [docs/app-plan.md](docs/app-plan.md) for the full plan.
